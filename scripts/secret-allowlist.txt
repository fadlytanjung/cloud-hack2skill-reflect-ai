# Format:  sha256:<first 16 hex of the SHA-256 of the value>   # why it is safe
#
# Fingerprints, never values. A 16-hex prefix identifies a value across scans
# without putting the value in the repository.
#
# Add an entry ONLY for something that is public by design. A real credential
# does not belong here: rotate it instead.
#
# To compute a fingerprint:
#   printf '%s' "<the value>" | shasum -a 256 | cut -c1-16
